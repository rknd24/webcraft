# 001 4択形式にする

## 状況
このプロダクトの目的は、作る過程でWeb技術と知識を学ぶこと。
完成後に自分が使い続けることは目的にしていない。
一度は「知識メモ＋AIの記述式出題」を検討したが、目的に照らして見直した。

## 決定
自分で問題を作り、4択形式で出題する。

## 理由と諦めたこと
- 理由：知識が定着するのは作問する時なので、出題形式の差は小さい
- 理由：AIの採点など重い部分をなくし、DB設計・認証・トランザクションに時間を使える
- 理由：選択肢をどうテーブルに持つかが、DB設計の題材になる
- 諦めたこと：解く時は問題文で答えを思い出せてしまい、理解の確認としては弱い

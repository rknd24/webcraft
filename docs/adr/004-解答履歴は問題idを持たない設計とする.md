# 004-解答履歴は問題idを持たないような設計にする

## 状況
DB設計をするに当たって、解答履歴に問題IDもしくは選択肢IDのどちらを紐付けるか判断に迷っていた

## 決定
解答履歴には選択肢IDを外部キーとして紐付ける設計にした

## 理由と諦めたこと
理由として、もし解答履歴が問題IDを持つ場合、画面から細工された値や、プログラムのバグによって、選択肢と問題IDの組みあわせが食い違った記録ができてしまう恐れがあったり、もし選択肢をそのまま別の問題に移したとき、DBに矛盾が生じてしまうため。選択肢IDを外部キーとすることで、選択肢をたどって問題も特定することができる。要は履歴にも問題IDを持たせると、同じ情報（その解答がどの問題のものなのか）が二重になってしまい、食い違いが起こったときにどちらが正しいかわからなくなってしまう
諦めたこととして、問題ごとの集計に選択肢との結合が必要になる。

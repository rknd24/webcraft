# 002-Alembicのマイグレーションを用いる

## 状況
DBのテーブルを作成することを考えたときにcreate_allかAlembicどちらを選ぶかを迷っていた。

## 決定
Alembicを用いる。

## 理由
Newscrapeを作った際にはschemaが安定しており、テーブルも一つしかなかったため、Alembicのマイグレーションを導入する意味は学習コストの重さを考えたとき割に合わないと考えて導入しなかった。WebCraftでは、テーブルの数が複数あり、まだschemaを変更する可能性もあるので、学習を行うにも適していると判断。create_allは既存のテーブル構造を変えないと公式ドキュメントで確認した。
